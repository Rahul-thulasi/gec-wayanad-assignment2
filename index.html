Assignment 3 • Full-Stack RESTful Architecture

MySQL Relational Database & PHP Session Authentication

The GEC Wayanad Project Showcase Portal has been upgraded to KTU CST463 Assignment 3 specifications, transitioning from static file storage to an enterprise-grade MySQL-backed relational architecture with server-side session authentication.

Institutional records are structured across normalized relational tables (projects, students, faculty, technologies, project_members, project_technologies, users) within database gec_assignment3. Foreign keys, indexes, and transactions ensure strict referential integrity.

The PHP REST API (api/items.php) delivers public data retrieval, debounced live search (GET /api/items.php?q=keyword), and authenticated record creation (POST) and modification (PUT) using secure PDO prepared statements, transaction boundaries, and PHP sessions ($_SESSION) with HttpOnly cookies.

The frontend communicates exclusively via asynchronous Fetch API requests without full-page reloads, featuring real-time DOM updates, loading states, and responsive modal dialogs.

Assignment 3 Architecture Highlights

  • Relational MySQL Schema: 3NF normalized tables with foreign key cascades and composite indexes in gec_assignment3.
  • Secure PDO Layer: 100% prepared statements preventing SQL injection, UTF-8 character encoding, and sanitized exception handling.
  • Server-Side Live Search: Debounced live search querying indexed database fields across titles, domains, technologies, and teams.
  • Session Authentication: Cookie-based authentication protecting POST/PUT mutations with regeneration and HttpOnly flags.
